# Taiwan Logo Wall

项目网址：www.easonzhan.cyou

## 项目简介

这是一个由 **ChatGPT-5.5 模型辅助生成与优化** 的台湾知名企业可视化网页项目。

页面以 Logo 墙的形式展示约 110 家台湾知名企业，并结合公司数据总览、国际知名度排名、国际影响力排名、行业分类、公司简介和搜索功能，帮助用户快速了解台湾主要企业在全球产业链中的位置。

## 项目亮点

- 展示约 110 家台湾知名企业 Logo
- 支持点击 Logo 查看公司详细信息
- 支持公司名称、股票代码、行业关键词搜索
- 提供国际知名度排名与国际影响力排名
- 包含公司行业分类与简要介绍
- 适配电脑端、平板端和手机端
- 使用纯 HTML / CSS / JavaScript 构建
- 可部署到 GitHub Pages、Cloudflare Pages 等静态网站平台

## 页面内容

网页主要展示台湾地区具有代表性的企业，涵盖：

- 半导体制造
- IC 设计
- 电子制造服务
- 电脑与消费电子
- 航运
- 金融
- 食品与零售
- 自行车与运动品牌
- PCB 与电子零组件
- 游戏、软件与互联网相关企业

页面通过 Logo 墙和数据表结合的方式，让用户既能直观看到台湾企业品牌分布，也能通过排名、行业和简介进一步了解每家公司。

## 功能说明

### Logo 墙展示

页面主体以 Logo Wall 的形式展示台湾知名企业 Logo，用户可以直观看到台湾企业品牌矩阵。

### 公司详情卡片

点击 Logo 后，会显示该公司的详细信息，包括：

- 公司名称
- 股票代码
- 所属行业
- 国际知名度排名
- 国际影响力排名
- 公司简介

### 公司数据总览

页面下方提供公司数据表，方便用户查看完整公司列表。

### 搜索功能

支持搜索：

- 公司名称
- 股票代码
- 所属行业

例如可以搜索：

- 台积电
- 2330
- 半导体
- 航运
- 金融

### 移动端适配

网页针对手机端进行了布局优化，使 Logo 墙、数据表和详情卡片在移动设备上也能正常浏览。

## 数据说明
